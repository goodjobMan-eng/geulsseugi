# 물리엔진 보관판

`index_전체기능.html`은 2026-11-26에 기능을 빼기 직전의 글쓰기(성인용) 앱 전체입니다.
나중에 물리엔진을 제대로 만들 때 이 판에서 다시 가져다 씁니다.

이 판에만 남아 있는 것
- 고급 설정 「연필 깎은 정도」(뭉툭 0 ~ 100 뾰족) — 굵기·진하기·연필 소리가 함께 바뀜
- 샤프심 길이 계산(딸깍 0.5mm, 최대 3mm, 약 6m 쓰면 0.5mm 닳음)과 펜 옆 버튼·두 손가락 톡 딸깍 코드

본판(`../index.html`)에서는 연필이 늘 뾰족한 상태(90)로 고정되고, 샤프심은 닳지 않습니다.
