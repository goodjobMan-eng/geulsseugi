# 글쓰기 — 원고지와 공책

태블릿과 펜으로 **진짜 원고지·공책에 쓰듯** 글을 쓰는 무료 웹앱입니다(쓰기공책 성인용).
가입 없음, 기록은 기기 안에만 저장, 한 번 열면 인터넷 없이도 씁니다.

▶ **바로 열기:** https://goodjobman-eng.github.io/geulsseugi/

- 원고지(가로·세로), 공책 줄, 무지 — 종이 색과 칸 크기를 고를 수 있음
- 연필·볼펜·사인펜·만년필 등 필기구, 필압·기울기, 쓰는 소리
- 지우개 여러 종류와 지우개 가루 털기, 되돌리기
- 장 넘기기(가장자리를 밀기), 장 찢기(위에서 쓸어내리기), 원고함에 저장·불러오기
- 가벼운 모드(고급 설정): 보급형 태블릿에서도 빠르게

아이용 받아쓰기 앱은 [쓰기공책](https://github.com/goodjobMan-eng/sseugi)에 있습니다.

## 태블릿에 설치하기
크롬에서 주소를 연 뒤 메뉴 → **홈 화면에 추가(앱 설치)**.
